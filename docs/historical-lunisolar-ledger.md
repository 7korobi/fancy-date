# 歴史的太陰太陽暦レコード台帳 — 天保暦期の慶応4／明治1（1868）

国立天文台が示す天保暦の期間（1844–1872）にある、慶応4／明治1・戊辰（1868）の
大小暦表から、指定された7か月 `2, 3, 4, 閏4, 5, 6, 7` だけを転記する [N1]。
歴史表は転記のみとし、日付計算や天文イベントの再構成は行わない。現行サンプルモデルとの
探索的な照合は、末尾の別節に分けて記す。

## フィールド

| フィールド                 | 定義                                                             |
| -------------------------- | ---------------------------------------------------------------- |
| `window_order`             | この台帳内での月の順序。1868年全体の通し番号ではない。           |
| `year_label`               | 参照表の西暦・元号・干支表記。                                   |
| `month_label`              | 参照表の月表記。`閏`を含めて保持する。                           |
| `month_number`             | 月表記の数値部分。通常月と閏月は同じ番号になる。                 |
| `is_leap`                  | 参照表の `閏` 表記から転記した値。天文計算による判定ではない。   |
| `month_size`               | 参照表の「大の月」「小の月」の分類。                             |
| `nominal_days`             | 同ページの説明に従い、大を30日、小を29日と記した月の長さ。       |
| `gregorian_start`          | 出典が直接示す月初日の西暦日付。出典にない場合は `—`。           |
| `source`                   | レコード値を転記した出典キー。                                   |
| `transcription_confidence` | 出典の表を正確に読み取れた確度。歴史的な一次証言の確度ではない。 |
| `limitations`              | 各行に共通する、出典の種類と欠けている情報。                     |

`高*` は、NDLの公開表に表示された月名と大小を転記した確度が高いことを表すだけで、
1868年当時の暦面・観測記録との照合を意味しない。`—` は日付が存在しないという意味
ではなく、ここで引用する出典が月初日の西暦日付を示していないことを表す。

## 7か月の記録

NDLの1868年行は、大の月を `2, 3, 5, 8, 10, 11`、小の月を
`1, 4, 閏4, 6, 7, 9, 12` とする [N1]。以下はそのうち指定された窓である。

| window_order | year_label               | month_label | month_number | is_leap | month_size | nominal_days | gregorian_start | source | transcription_confidence |
| -----------: | ------------------------ | ----------- | -----------: | :-----: | :--------: | -----------: | --------------- | ------ | ------------------------ |
|            1 | 1868・慶応4／明治1・戊辰 | 2           |            2 |  false  |     大     |           30 | —               | [N1]   | 高\*                     |
|            2 | 1868・慶応4／明治1・戊辰 | 3           |            3 |  false  |     大     |           30 | —               | [N1]   | 高\*                     |
|            3 | 1868・慶応4／明治1・戊辰 | 4           |            4 |  false  |     小     |           29 | —               | [N1]   | 高\*                     |
|            4 | 1868・慶応4／明治1・戊辰 | 閏4         |            4 |  true   |     小     |           29 | —               | [N1]   | 高\*                     |
|            5 | 1868・慶応4／明治1・戊辰 | 5           |            5 |  false  |     大     |           30 | —               | [N1]   | 高\*                     |
|            6 | 1868・慶応4／明治1・戊辰 | 6           |            6 |  false  |     小     |           29 | —               | [N1]   | 高\*                     |
|            7 | 1868・慶応4／明治1・戊辰 | 7           |            7 |  false  |     小     |           29 | —               | [N1]   | 高\*                     |

**共通する制約:** [N1] は回顧的な大小月一覧であり、当時の暦面を日付まで転写した
ものではない。したがって、この7行には直接確認できる西暦月初日、朔・中気の瞬時刻、
同時代の観測記録を付していない。閏4の配置理由も推定しない。UTC・JSTの時刻値はなく、
1868年の日時に現行のJST（UTC+9）を遡及適用しない。

## 出典と根拠の範囲

- **[N1]** [国立国会図書館「日本の暦」第2章「暦の中身」・大小月の表](https://www.ndl.go.jp/koyomi/chapter2/s1.html)。
  1868年の大小月リストと、大の月・小の月の説明に使用した。
- **[N2]** [国立国会図書館「日本の暦」参考文献](https://www.ndl.go.jp/koyomi/references/index.html)。
  「日本の暦」の主な参考文献として、内田正男『日本暦日原典 第4版』雄山閣出版、
  1992年6月、請求記号 MB96-E17 を掲げる。これは展示全体の参考文献情報であり、
  NDLの1868年行が同書のどの箇所に直接対応するかまでは示していない。
- **[N3]** NDLデジタルコレクション
  [『〔絵暦貼込帳〕』](https://doi.org/10.11501/1286722)（新城文庫、寄別13-64、
  `info:ndljp/pid/1286722`。閲覧用[コマ65](https://dl.ndl.go.jp/info:ndljp/pid/1286722/65)）。
  [N1]の展示記録はこの資料を1868年・河鍋暁斎画の大小暦として紹介する。所蔵品の存在・
  来歴を示す資料としてのみ挙げ、絵の月記号は独立に判読していないため、上表の月名・
  大小の転記根拠にはしていない。
- **[N4]** 国立天文台「[江戸時代の暦](https://eco.mtk.nao.ac.jp/koyomi/yoko/edo.html)」は
  「慶応04年 (1868)」の[所蔵暦ビューア](https://library.nao.ac.jp/kichou/archive/9474/kmview.html)
  にリンクする。ビューアの本文・内部タイトルは確認できていないため、所蔵品の存在を
  補うだけで、月ごとの記録には使用していない。
- **[N5]** 国立天文台「[暦Wiki・天保暦](https://eco.mtk.nao.ac.jp/koyomi/wiki/C5B7CADDCEF1.html)」は
  期間を天保15年（1844）から明治5年（1872）とし、「定数」欄に定朔・定気を列記する。
  また「[渋川景佑と天保暦](https://eco.mtk.nao.ac.jp/koyomi/wiki/CEF2BBCB2FC6FCCBDCA4CECEF12F5.BDC2C0EEB7CACDA4A4C8C5B7CADDCEF1.html)」
  は二十四節気に定気法を採用したと説明する。これは天保暦の期間・方法の文脈であり、
  1868年の各月境界や閏月決定の根拠を示すものではない。

各ウェブページは2026-10-12に確認した。

## fancy-date の現行サンプルモデルとの比較（探索的出力）

**以下は既存サンプル `Calendar.定気法` の探索的な計算出力であり、天保暦の算法、
1868年の公式暦、または同時代の観測記録ではない。** NDLの表が直接示す月初日を
復元したものでもない。

[`Calendar.定気法`](../src/sample/calendars.ts) は1969年を起点とするサンプルで、
[`天文東京`](../src/sample/astro.ts)（東京、UTC+09）を使う。
[天文出典メモ](astronomy-sources.md)によれば、太陽はVSOP87系、月はMeeus系の近似式で、
国立天文台の暦要項そのものの公式アルゴリズムではない。1868年の出力はこの現行モデルを
過去へ適用した計算値であり、[astro-math.ts](../src/naoj/astro-math.ts) のΔT近似も含め、
史料上の時刻や観測精度を表さない。

下表の開始・終了境界（終了は含まない）は `m.last_at` / `m.next_at` を、このサンプルの
固定UTC+09で表示した時刻である。`Calendar.定気法.calc.zero.day` は
`1969-12-08T14:00:00.000Z`（固定UTC+09表示では `1969-12-08T23:00:00.000+09:00`）で、
このサンプルでは太陽イベントによる `dayStart` を設定していない。`lunisolar()` が返す
対象7か月の全開始・終了境界はUTCで14:00:00.000Z、固定UTC+09表示で23:00:00.000+09:00に
なる。表の日付はその境界時刻の表示年月日であり、00:00を起点とする日付の開始ではない。
固定UTC+09はモデル出力を示す便宜にすぎず、1868年当時の標準時・時計時刻や現地日境界の
慣行については推定せず、この出力からは分からないものとして扱う。また、NDL [N1] が
示していない月初日を補うものでもない。イベント時刻はモデルの値をISO形式のUTC分表示に
整形したもの（秒以下切捨て）であり、1868年の実測UTC/JST時刻ではない。

リポジトリルートで次を実行すると、指定窓の行を再現できる。

```sh
bun -e '
import { Calendar } from "./src/sample/calendars.ts";

const g = Calendar.定気法;
const day = 24 * 60 * 60 * 1000;
const jst = 9 * 60 * 60 * 1000;
const boundaryTime = (at) => new Date(at + jst).toISOString().replace(/Z$/, "+09:00");
const utcMinute = (at) => `${new Date(at).toISOString().slice(0, 16)}Z`;

console.log(
  "month\tdays\tstart(+09:00)\tend-exclusive(+09:00)\tprincipal-term-month\tnew-moon(UTC)\tprincipal-term(UTC)",
);
for (let at = Date.UTC(1866, 0, 1); at < Date.UTC(1869, 0, 1); ) {
  const m = g.lunisolar(at);
  if (m.year === 1868 && m.month >= 2 && m.month <= 7) {
    console.log(
      [
        `${m.is_leap ? "閏" : ""}${m.month}`,
        (m.next_at - m.last_at) / day,
        boundaryTime(m.last_at),
        boundaryTime(m.next_at),
        m.principal_term?.month ?? "—",
        utcMinute(m.new_moon_at),
        m.principal_term ? utcMinute(m.principal_term.at) : "—",
      ].join("\t"),
    );
  }
  at = m.next_at;
}
'
```

| -------- | ----------------------------- | ------------------------------------ | ---: | ---------------------: |
| 2        | 1868-02-23T23:00:00.000+09:00 | 1868-03-23T23:00:00.000+09:00        |   29 |                      2 |
| 3        | 1868-03-23T23:00:00.000+09:00 | 1868-04-22T23:00:00.000+09:00        |   30 |                      3 |
| 4        | 1868-04-22T23:00:00.000+09:00 | 1868-05-21T23:00:00.000+09:00        |   29 |                      4 |
| 閏4      | 1868-05-21T23:00:00.000+09:00 | 1868-06-20T23:00:00.000+09:00        |   30 |                      — |
| 5        | 1868-06-20T23:00:00.000+09:00 | 1868-07-19T23:00:00.000+09:00        |   29 |                      5 |
| 6        | 1868-07-19T23:00:00.000+09:00 | 1868-08-17T23:00:00.000+09:00        |   29 |                      6 |

イベント時刻も同じ現行モデルによる計算値であり、UTC表記は便宜上のものとして分単位で示す。

| モデル月 | `new_moon_at` (UTC) | `principal_term.at` (UTC) |
| -------- | ------------------- | ------------------------- |
| 2        | 1868-02-23T14:18Z   | 1868-03-20T07:41Z         |
| 3        | 1868-03-24T06:57Z   | 1868-04-19T19:39Z         |
| 4        | 1868-04-22T20:17Z   | 1868-05-20T19:38Z         |
| 閏4      | 1868-05-22T06:34Z   | —                         |
| 5        | 1868-06-20T14:43Z   | 1868-06-21T04:08Z         |
| 6        | 1868-07-19T21:54Z   | 1868-07-22T15:04Z         |
| 7        | 1868-08-18T05:09Z   | 1868-08-22T21:41Z         |

この窓ではモデルの月ラベルと閏4の位置はNDL [N1] の列と一致する。月長は2（モデル29日／
NDL 30日）、閏4（30日／29日）、5（29日／30日）で異なり、3・4・6・7では一致する。
比較対象は月ラベル・閏月配置・月長だけであり、NDLの `gregorian_start` は引き続き `—`
のままにする。上記のモデル開始境界はNDLの月初日データではない。差異はstep 5で調べる候補で
あって、歴史的誤りや差異の説明が確定したことを意味しない。

## 再現・拡張方法

1. [N1] の年順表から1868年の行を開き、大・小の月リストをそのまま確認する。
2. 指定窓の月ラベルを月順に並べ、`month_number` は数字部分、`is_leap` は `閏` の有無、
   `month_size` は元の大小リストへの所属から転記する。日数は同ページの大小月の定義だけ
   から記す。
3. 一次資料などに直接記された西暦日付が見つかるまでは `gregorian_start` を `—` のまま
   にする。月の大小や天文計算だけから歴史上の日付を補わない。
4. 年を追加するときは、原表記・西暦／元号・出典キー・ページまたはコマ・資料種別
   （同時代資料か回顧的編纂か）・確認日を記録する。後から得た模型計算は、採用API・
   model/options・時間基準・アンカーを明記した別データとして保持し、史料転記と混ぜない。
